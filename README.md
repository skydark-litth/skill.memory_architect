# memory-architect（记忆架构师）

把记忆文件从「记案例」升级为「记规律」：审计 → 诊断 → 待删清单 → 提炼规律 → 生成元规则 → 落点路由。

> 本 skill 只做「流程编排与记忆蒸馏整理」。它是一个**纯指令型技能**——不依赖任何外部服务、连接器或第三方库，`scripts/scan_memory.py` 只用 Python 标准库，可直接运行。

## 适用场景

- 记忆文件越记越乱、案例流水账越堆越多，想整理成规律；
- 想给记忆文件做一次「体检」，找出死链、重复案例、过期内容；
- 想把散落在各处的元规则（不绑定具体问题的通用原则）汇总到一处；
- 定期清理超过 30 天的日志、把其中有价值的部分蒸馏进长期记忆。

## 核心特性

- **三层记忆全覆盖**：用户级（`~/.workbuddy/user-*/MEMORY.md`）、项目级（各工作区 `.workbuddy/memory/MEMORY.md`）、任务级（每日日志 `YYYY-MM-DD.md`），并覆盖旧位置与历史快照。
- **先诊断后动手**：严格按「读全量 → 诊断 → 出待删清单 → **停下等用户确认** → 才落盘」执行，绝不先斩后奏。
- **案例 → 规律 → 元规则三级蒸馏**：把「这次发生了什么」抽象为「遇到这种情况该怎么做」，再进一步抽象为不绑定具体问题的元规则。
- **规律三段式**：每条规律统一为「规律 + Why + 覆盖变体」。
- **安全删除规程**：删除前逐项确认、删除后到对应卷回收站核实 `$I/$R` 成对存在（可还原）才算完成。
- **先备份再改写**：任何写回前先创建 `<文件名>.bak-<时间戳>` 快照。
- **外发脱敏红线**：技能文件、汇报、README、脚本在对外发布/分享/上传前，必须替换本地盘符与路径、真实项目名、用户名、账号为通用占位符，并对整个待发布目录复扫确认零残留；已推送过的敏感内容须清空推送历史（删库重建空库）以防被还原。
- **只读扫描脚本**：`scripts/scan_memory.py` 一次列出所有记忆文件、行数、历史快照、超期日志与引用死链，不做任何修改。

## 工作流概览

| 步骤    | 内容                                     |
| ----- | -------------------------------------- |
| 第 0 步 | 定位所有记忆文件（三层 + 旧位置 + 快照；`maxdepth ≥ 4`） |
| 第 1 步 | 报告每个文件的行数                              |
| 第 2 步 | 诊断：案例流水账 / 规律 / 元规则 / 死链过期的判定与计数       |
| 第 3 步 | 输出待删清单 + 结构草稿 → **停下等用户确认**            |
| 第 4 步 | 落点路由：规律写回来源文件，元规则汇总到用户级                |
| 第 5 步 | 用户级记忆文件整体修订（四区结构）                      |
| 第 6 步 | 生成任务汇报（8 个标准小节，含「修改过的文件明细」）            |

> 完整细节见仓库内 [`SKILL.md`](./SKILL.md)。

## 设计原则

- **渐进式披露**：不可妥协的红线（如「不得丢知识点」）放在 `SKILL.md` 常驻区，确保执行时必定加载；细则放 `references/`，按需加载，保持主文件精简（125 行）。
- **明确拒绝重流程**：不拆原子化能力卡、不引并行子 agent。元规则的生成依赖**跨条目抽象归纳**，卡片化会使抽象层消失；且本技能含强制停等确认环节，与子 agent 不兼容。
- **脚本做机械活、AI 做判断活**：扫描/统计/死链检测交给脚本，诊断/提炼交给模型。

## 环境准备

无需安装依赖。`scan_memory.py` 只用 Python 3 标准库：

```bash
python3 scripts/scan_memory.py --workspace <工作区根目录>
python3 scripts/scan_memory.py --workspace <工作区根> --json   # JSON 输出
```

输出示例（本机实测）：

```
[用户级] MEMORY.md  55 行  2026-10-10 11:05
[项目级] <项目名>/MEMORY.md  92 行  2026-10-10 11:12
[每日日志] <项目名>/2026-08-03.md  65 行  2026-08-03 17:19  [过期 68 天]
合计 16 个文件、1034 行。
```

## 安全与数据说明

- **纯本地运行**：脚本只读本地文件，不联网、不上传任何数据。
- **破坏性操作需授权**：删除、覆盖等动作必须先经用户逐项确认；删除后核实回收站可还原性。
- **先备份后改写**：写回记忆文件前必定创建时间戳备份。
